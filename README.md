# INFR3120-Fall26-Project
# Project Part 1 – First Release

## About
MovieTrack is a web application for keeping a personal list of movies. Users can add movies, search and view the list, in the first release of this web application.

## Live Site
https://infr3120-fall26-project-vzxr.onrender.com/

## Features (Part 1)
- Landing page with site name and team logo
- Hero button to add a new movie
- Table listing all saved movies
- Search movies by title
- Deployed to the cloud

## Tech Stack
- Node.js and Express
- EJS (views)
- MongoDB with Mongoose
- Bootstrap and Font Awesome
